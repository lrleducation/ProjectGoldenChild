PROJECT GOLDEN CHILD v2.5.0 — MEDALLION WEBSITE REDESIGN

This is a design-only release based on the approved circular gold Project Golden Child emblem.

WHAT CHANGES
- New circular medallion becomes the main website brand mark.
- Homepage hero redesigned around the medallion rather than a rectangular logo image.
- Ivory, cream, gold, bronze and deep brown become the core website palette.
- Gold ring / glow / sparkle details echo the emblem without making pages difficult to read.
- Cards, forms, event pages, buttons, page headers and footer have been restyled consistently.
- The medallion is also used for the website favicon and compact navigation mark.
- Mobile and tablet layouts have been adjusted for the circular artwork.

WHAT DOES NOT CHANGE
- No database changes.
- No Supabase SQL.
- No Vercel environment variable changes.
- Referrals, Harper's Heroes, postal address fields, event posters, photographs, communications and AI event reviews remain intact.
- Admin functionality remains intact; it simply inherits the new compact brand mark.

INSTALL
1. Extract this ZIP.
2. Replace the current website files in your GitHub repository, keeping the hidden .git folder.
3. GitHub Desktop commit:
   Project Golden Child v2.5.0 medallion redesign
4. Commit to main -> Push origin.
5. Wait for Vercel to show Ready.
6. Press Ctrl+F5 once on the live website.
7. Check Home, Harper's Heroes, Events, Register a child and one mobile view.

NO SUPABASE SQL IS REQUIRED.
