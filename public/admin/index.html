Referrals

Events
Draft, publish, complete and archive events. Published records drive the public events page.
Event stories
Use typed or dictated notes to create a draft. Nothing is published until you choose to publish the event.

Privacy by design

The public site cannot query Hero or referral tables directly. Sensitive data is returned only through authenticated admin endpoints. Changes to key records are written to the audit log.
