# Launch checklist

- [ ] Foundation CIO registration wording on the website is accurate on launch day.
- [ ] Final privacy notice approved and published.
- [ ] Safeguarding policy and reporting routes approved.
- [ ] Beneficiary eligibility/referral process approved.
- [ ] DPIA completed for the child/family database and special-category health data.
- [ ] Supabase project belongs to Project Golden Child and uses MFA for administrators.
- [ ] Service-role key is stored only as a server-side Vercel secret.
- [ ] Named admin accounts created; no shared production login.
- [ ] Authenticator app tested for every admin.
- [ ] Event image bucket contains only images cleared for public use.
- [ ] `/refer`, `/contact`, `/go-gold`, `/events` and `/admin` tested on Preview.
- [ ] Email notifications contain references only and no diagnosis/medical detail.
- [ ] Mobile navigation and accessibility checked.
- [ ] Domain, HTTPS and sender email verified.
